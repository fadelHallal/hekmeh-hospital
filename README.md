# Hekmeh Hospital — website concept

A design concept for the Hekmeh Hospital website (Nabatieh, Lebanon) by Fadel Hallal.
**Not the official hospital website.** Doctor profiles are samples and the forms don't send anything.

Live: https://fadelhallal.github.io/hekmeh-hospital/

Single-file static site (`index.html`): bilingual English/Arabic (RTL), light/dark mode, adjustable text size,
appointment booking flow, doctor search, department details, insurance/guarantors, patient info and contact.
